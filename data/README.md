# Демофайлы

`demo-video.webm` — синтетическая тестовая таблица FFmpeg `testsrc2`, 960 × 540, 10 кадров/с, 8 секунд, VP8 без звуковой дорожки. Создана командой:

```sh
ffmpeg -f lavfi -i 'testsrc2=size=960x540:rate=10:duration=8' -c:v libvpx -b:v 96k -an demo-video.webm
```

`demo-audio.wav` — синтезированный тон 330 Гц, 8 секунд, моно PCM 16 бит / 16000 Гц с коротким плавным началом и окончанием, амплитуда не выше 700 из 32767. Деморежим открывает его с выключенным звуком.

`demo-voice.ogg` — вымышленная реплика, синтезированная eSpeak NG и закодированная в моно Opus. Звуковая волна рассчитана по пиковым значениям 48 отрезков этой записи. Деморежим открывает её с выключенным звуком.

Файлы не содержат реальных записей, переписки или личных данных. Как и код проекта, распространяются по GPL-3.0-only.

`demo-sticker.png` и `demo-sticker.webp` — один синтетический рисунок кота из геометрических фигур, созданный для tgrust. PNG используется в демоинтерфейсе, WebP без потерь — для ручного сохранения. Три пункта демонстрационного набора используют один рисунок; тип указан во всплывающей подсказке. Анимации TGS и WebM используют отдельные синтетические файлы. Лицензия GPL-3.0-only.

`demo-sticker-video.webm` — синтетическое покачивание того же кота, 512 × 512, VP9 с прозрачностью, 15 кадров/с, 2 секунды без звука. Размер меньше 256 КиБ. Создан командой:

```sh
ffmpeg -loop 1 -i demo-sticker.png -vf 'scale=512:512,format=yuva420p,rotate=0.08*sin(2*PI*t):ow=512:oh=512:c=none' -t 2 -r 15 -c:v libvpx-vp9 -pix_fmt yuva420p -crf 40 -b:v 0 -an demo-sticker-video.webm
```

`demo-sticker-tgs.json` — исходник синтетического векторного кота для rlottie: простые эллипсы и треугольники с покачиванием, 512 × 512, 60 кадров/с, 2 секунды. `demo-sticker.tgs` содержит этот JSON без завершающего перевода строки, сжатый gzip с `mtime=0`. Все фигуры созданы для tgrust, внешние изображения и шрифты не используются. Лицензия GPL-3.0-only.

~~~sh
python3 -c 'import gzip,pathlib; p=pathlib.Path("demo-sticker-tgs.json"); pathlib.Path("demo-sticker.tgs").write_bytes(gzip.compress(p.read_bytes().rstrip(b"\n"),mtime=0)))'
~~~
