# tgrust

Русский · [English](README.en.md)

Неофициальный клиент Telegram для GNOME/Wayland на Rust, GTK 4 и Libadwaita.

## Быстрый старт

Для Fedora 45 x86_64 скачайте `tgrust-fedora45-x86_64` из [последнего выпуска](https://github.com/skae798/tgrust/releases/latest). Из папки со скачанным файлом установите клиент и запустите деморежим.

~~~sh
sudo dnf install gtk4 libadwaita gstreamer1-plugins-base gstreamer1-plugins-good gstreamer1-plugins-bad-free
install -Dm755 ./tgrust-fedora45-x86_64 ~/.local/bin/tgrust
~/.local/bin/tgrust --demo
~~~

Деморежим работает без аккаунта. Для входа запустите tgrust без `--demo`, сохраните собственные [данные приложения Telegram](https://my.telegram.org/apps) в разделе «Аккаунты» → «Ключи приложения Telegram» и войдите по QR-коду или номеру телефона.

Готовый выпуск проверяет обновления автоматически и открывает новую сборку при следующем запуске. В GNOME/Wayland обычный запуск использует Wayland, в том числе после обновлений. Фоновые графические проверки запускаются в отдельном дисплее и D-Bus через `scripts/test-ui.sh`, включая запускаемые порталы. Перед публикацией обновления CI проверяет Wayland на готовом исполняемом файле.

## Возможности

- **Сообщения** — подгрузка истории при прокрутке, поиск, ответы, правки и реакции. Выполненные действия сохраняются при переключении чатов.
- **Опросы** — опросы и викторины, сроки, скрытые итоги, запрет переголосования, перемешивание ответов и участие только подписчиков в каналах и супергруппах, ограничения по странам номера аккаунта. Показываются фото и видео, приложенные к вопросу. В публичных опросах доступен список проголосовавших; в обычных публичных — добавляемые участниками варианты.
- **Медиа** — альбомы, потоковое видео и музыка, голосовые в сообщениях, отдельный просмотр фото и видео. Медиа со спойлером скрыты до явного раскрытия.
- **Чаты** — создание групп и каналов, включение тем в супергруппах и управление ими, папки, архив, уведомления GNOME, управление участниками и администраторами, общие и персональные ограничения, медленный режим, приглашения, публичные адреса и журнал действий.
- **Аккаунты** — отдельные окна, настройки профиля и конфиденциальности, управление сеансами, SOCKS5.
- **Стикеры** — поиск по эмодзи, открытие наборов по ссылке, установка и удаление, недавние и избранные, отправка в чат или тему с ответом. WebP показываются целиком; видеостикеры повторяются прямо в сообщении с прозрачностью и без звука. Анимации TGS проигрываются в сообщениях одновременно, с учётом масштаба монитора. В истории и окне выбора стикеры показываются без подписей.

Для сборки из исходников также нужны C++ и пакеты `gstreamer1-devel`, `gstreamer1-plugins-base-devel`; полный список приведён в руководстве.
