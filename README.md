# tgrust

Русский · [English](README.en.md)

Неофициальный клиент Telegram для GNOME/Wayland на Rust, GTK 4 и Libadwaita.

## Быстрый старт

Для Fedora 45 x86_64 скачайте `tgrust-fedora45-x86_64` из [последнего выпуска](https://github.com/skae798/tgrust/releases/latest). Из папки со скачанным файлом установите клиент и запустите деморежим.

~~~sh
sudo dnf install gtk4 libadwaita gstreamer1-plugins-base gstreamer1-plugins-good
install -Dm755 ./tgrust-fedora45-x86_64 ~/.local/bin/tgrust
~/.local/bin/tgrust --demo
~~~

Деморежим работает без аккаунта. Для входа запустите tgrust без `--demo`, сохраните собственные [данные приложения Telegram](https://my.telegram.org/apps) в разделе «Аккаунты» → «Ключи приложения Telegram» и войдите по QR-коду или номеру телефона.

Готовый выпуск проверяет обновления автоматически и открывает новую сборку при следующем запуске.

## Возможности

- **Сообщения** — подгрузка истории при прокрутке, поиск, ответы, правки, реакции и опросы.
- **Медиа** — альбомы, потоковое видео и музыка, голосовые в сообщениях, отдельный просмотр фото и видео.
- **Чаты** — создание групп и каналов, папки, архив, уведомления GNOME, управление участниками и администраторами, общие и персональные ограничения, медленный режим, приглашения, публичные адреса и журнал действий.
- **Аккаунты** — отдельные окна, настройки профиля и конфиденциальности, управление сеансами, SOCKS5.
