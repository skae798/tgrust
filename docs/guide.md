# Руководство tgrust

[README на русском](../README.md) · [English README](../README.en.md) · [Проверки](testing.md)

## Установка

### Сборка на Fedora

Понадобятся Rust 1.100.0 или новее, GTK 4.16 и Libadwaita 1.6 или новее. Для сборки встроенной базы сессий требуются CMake и libclang. Для TGS требуется C++: rlottie собирается статически из зафиксированных локальных исходников. Готовому клиенту отдельная установка rlottie не нужна. Репозиторий включает локальные правки grammers 0.12.0 для глобального поиска и SOCKS5. Их происхождение и проверки описаны в [patches/README.md](../patches/README.md).

```sh
sudo dnf install gcc gcc-c++ make cmake clang-devel pkgconf-pkg-config gtk4-devel libadwaita-devel gstreamer1-devel gstreamer1-plugins-base-devel gstreamer1-plugins-base gstreamer1-plugins-good gstreamer1-plugins-bad-free
rustup update stable
cargo build --locked
cargo run --locked -- --demo
```

### Готовый выпуск для Fedora 45 x86_64

После успешных проверок ветки `main` GitHub публикует нативный бинарник. Скачайте файл `tgrust-fedora45-x86_64` из [последнего выпуска](https://github.com/skae798/tgrust/releases/latest) и установите его один раз в `~/.local/bin/tgrust` с правами на запуск. Для работы нужны GTK и Libadwaita.

```sh
install -Dm755 ./tgrust-fedora45-x86_64 ~/.local/bin/tgrust
~/.local/bin/tgrust --version
```

Клиент проверяет выпуск при запуске и каждые шесть часов. Пункт «Обновления клиента» на экране входа и в меню приложения показывает состояние и позволяет проверить вручную. Проверка обращается к публичному API GitHub без авторизации. Клиент скачивает новую сборку, сверяет размер и SHA-256 из метаданных выпуска и атомарно заменяет бинарник. Обновление применяется при следующем запуске. Сессии и открытые окна сохраняются во время установки.

### Сборка и установка из исходников

Установите зависимости сборки, Git, `util-linux` и `desktop-file-utils`.

```sh
./scripts/update.sh
```

Скрипт скачивает актуальный коммит ветки `main`, собирает клиент с `Cargo.lock` и устанавливает бинарник в `~/.local/bin/tgrust`, а ярлык и значок — в каталог данных пользователя. Для этой установки используйте скрипт при повторной сборке. Если ярлык уже установлен, он подходит и для готового выпуска.

Ярлык tgrust появится в меню GNOME. Чтобы закрепить его в доке, выберите «Добавить в избранное». При запуске из меню или дока клиент использует сохранённую сессию.

### Установка и обновление Flatpak

На Fedora установите `flatpak`, `flatpak-builder`, Git и Cargo. Для сборки нужны GNOME SDK 51 и его расширение LLVM. Добавьте Flathub в пользовательскую установку и соберите пакет из коммита, который открыт в рабочей копии.

```sh
flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub org.gnome.Platform//51 org.gnome.Sdk//51 org.freedesktop.Sdk.Extension.llvm22//26.08
./scripts/build-flatpak.sh
flatpak install --user ./tgrust.flatpak
flatpak run io.github.skae798.tgrust --demo
```

Скрипт принимает путь к выходному пакету. Он берёт исходники из `HEAD` и скачивает зависимости по `Cargo.lock`. Компиляция выполняется без сети. Для обновления перейдите на новый коммит, пересоберите пакет и установите его командой `flatpak install --user --reinstall ./tgrust.flatpak`. Ярлык доступен в меню GNOME.

Для первого входа в Flatpak откройте «Аккаунты» → «Ключи приложения Telegram» и сохраните собственную пару. Конфигурация песочницы отделена от обычной установки.

Flatpak хранит свою сессию в `~/.var/app/io.github.skae798.tgrust/data/tgrust`. Для загрузки и отправки файлов используются разрешения, выданные системным диалогом. Воспроизведение использует кодеки платформы GNOME и аудиосокет PulseAudio, в том числе при работе через PipeWire.

## Вход и настройки аккаунта

При первом входе tgrust показывает QR-код. В Telegram на телефоне откройте «Настройки» → «Устройства» → «Подключить устройство». Код обновляется автоматически. Кнопка «Войти по номеру телефона» открывает форму номера и кода подтверждения. Telegram может дополнительно запросить облачный пароль. [Вход по QR-коду](https://core.telegram.org/api/qr-login).

Сборке нужны ключи собственного приложения Telegram. Если ключи ещё не заданы, откройте «Аккаунты» → «Ключи приложения Telegram» и один раз сохраните пару, полученную на my.telegram.org. Значения хранятся в `${XDG_CONFIG_HOME:-$HOME/.config}/tgrust/telegram-app.conf` с правами `0600`. При сборке дистрибутива можно задать пару `TGRUST_BUILD_API_ID` и `TGRUST_BUILD_API_HASH`. Для разового запуска по-прежнему подходят `TGRUST_API_ID` и `TGRUST_API_HASH` в окружении. [Ключи приложения Telegram](https://core.telegram.org/api/obtaining_api_id).

Если сохранилась одна сессия, tgrust открывает её автоматически. При нескольких сессиях выберите нужную через «Аккаунты». Кнопка «Добавить аккаунт» использует настроенную пару ключей и выбирает свободный локальный номер. В списке показываются известные имена и публичные имена аккаунтов. Закрытие окна сохраняет серверную сессию и останавливает её сетевые задачи. Для уведомлений аккаунта оставьте его окно открытым.

Изменить имя, фамилию и многострочное описание можно через меню «Мой профиль» или кнопку «Редактировать профиль» в «Избранном». Основное публичное имя сохраняется отдельно. Пустое поле удаляет его. Клиент сверяет редактируемые поля с Telegram перед записью. Если то же поле изменилось в другом клиенте, tgrust покажет актуальное значение. [Изменение профиля](https://core.telegram.org/method/account.updateProfile), [изменение публичного имени](https://core.telegram.org/method/account.updateUsername).

Кнопка «Изменить фото» открывает локальный файл JPEG или PNG до 20 МБ и 32 мегапикселей. Клиент обрезает фото по центру до квадрата, показывает его в круглом предпросмотре и отправляет после нажатия «Установить фото». [Загрузка фото профиля](https://core.telegram.org/method/photos.uploadProfilePhoto).

В «Прокси» включите SOCKS5, укажите адрес и порт, при необходимости заполните имя пользователя и пароль, затем нажмите «Сохранить». Настройка используется всеми аккаунтами. Для уже подключенного аккаунта переоткройте его окно. На экране входа после ошибки нажмите «Повторить подключение». При недоступном SOCKS5 попытка завершается ошибкой. Для перехода на прямое подключение отключите SOCKS5 и сохраните изменение. Поддержка MTProxy относится к отдельному этапу. [Типы прокси Telegram](https://core.telegram.org/proxy).

Параметры SOCKS5, включая пароль, хранятся в файле `${XDG_CONFIG_HOME:-$HOME/.config}/tgrust/proxy.conf` с правами `0600`. У Flatpak свой каталог конфигурации `~/.var/app/io.github.skae798.tgrust/config/tgrust`. Деморежим хранит параметры только в памяти.

В разделе «Конфиденциальность» выберите аудиторию и нажмите «Сохранить» под нужной настройкой. Клиент перечитывает её перед записью. Если правила уже изменились, диалог покажет новое значение и предложит выбрать аудиторию заново. Существующие исключения отправляются в прежнем порядке. Если Telegram изменит их при сохранении, диалог сообщит об этом. Для редактирования исключений и правил, которые tgrust может только показать, используйте другой клиент Telegram. У поиска по номеру две аудитории: «Все» и «Мои контакты». [Правила конфиденциальности Telegram](https://core.telegram.org/api/privacy).

Для блокировки откройте профиль нажатием на заголовок чата и подтвердите действие. Снять блокировку можно из профиля или из списка «Заблокированные». Кнопка «Загрузить ещё» подгружает следующую страницу. Если список открыт, изменения из другого клиента запускают загрузку с первой страницы. Действия относятся к основному списку блокировок открытого аккаунта. [Блокировки в Telegram](https://core.telegram.org/api/block).

Сессии находятся в `${XDG_DATA_HOME:-$HOME/.local/share}/tgrust`. Уже созданные файлы `<api_id>.session` и `<api_id>-<метка>.session` открываются как прежде. При добавлении tgrust выбирает свободное имя из того же формата и запоминает название аккаунта после авторизации. Файлы блокируются отдельно и открываются с правами `0600`. Каталог доступен только владельцу. Файл содержит ключ авторизации и даёт доступ к аккаунту. Храните его локально.

Для выхода выберите «Выйти из аккаунта» в меню нужного окна и подтвердите. После завершения серверной авторизации tgrust закрывает это окно, останавливает его фоновые задачи и удаляет только его базу SQLite и служебные файлы. Черновики этого аккаунта исчезают при закрытии. Для нового входа добавьте аккаунт с теми же ключами приложения. При сетевой ошибке или таймауте окно остаётся открытым и выход можно повторить. При ошибке локальной очистки приложение покажет сообщение. Серверный выход выполняется методом [auth.logOut](https://core.telegram.org/method/auth.logOut).

## Возможности

### Аккаунты

- Вход в существующий аккаунт по QR-коду или по номеру, коду подтверждения и облачному паролю. Локальная сессия позволяет запускать клиент повторно. После ошибки или таймаута подключения блокировка сессии освобождается для повторной попытки. Отменённое подключение и освобождение последнего владельца соединения останавливают его сетевую задачу.
- «Мой профиль» показывает имя и аватарку аккаунта. Можно менять имя, фамилию, описание, основное публичное имя и фото. Новые имя и аватарка видны в заголовке и в собственных сообщениях.
- Несколько аккаунтов в одном приложении. Каждое окно отдельно загружает историю аккаунта и хранит его черновики в памяти. Уведомления показывают метку аккаунта и открывают его окно.
- Прямое подключение или SOCKS5 с адресом, портом и необязательной аутентификацией. Настройка доступна до входа и из меню аккаунта.
- Настройки конфиденциальности аккаунта через меню «tgrust» → «Конфиденциальность». Можно выбрать, кто видит номер телефона, может найти по номеру, видит точное время последней активности и фотографии профиля.
- Блокировка и разблокировка в профилях пользователей, ботов и каналов. В меню «tgrust» → «Заблокированные» доступен основной список Telegram с аватарками, постраничной подгрузкой и разблокировкой.
- Список подключённых устройств через меню «tgrust» → «Устройства» или Ctrl+Shift+D. Показываются приложение, система, IP, местоположение, время входа и последней активности, а также отметки неподтверждённого сеанса и ожидания облачного пароля. Текущее устройство выделено отдельно. Можно завершить отдельный сеанс или все остальные после подтверждения; текущий сеанс сохраняется, список обновляется с сервера. Период автозавершения текущего сеанса выбирается из 1 недели, 1, 3, 6 месяцев или 1 года и применяется только по кнопке «Сохранить срок». Нестандартный срок, полученный от сервера, показывается без автоматической замены. Перед завершением клиент повторно проверяет выбранный сеанс. Закрытие окна «Устройства» отменяет загрузку списка, а подтверждённая команда продолжает выполняться. Сервер Telegram может ограничить действие для недавно подключённого устройства.

### Сообщения

- Последние 150 диалогов, автоматическая подгрузка истории при прокрутке вверх, отправка текста в личных чатах и группах. При открытии чата можно сразу писать. Enter отправляет сообщение, Shift+Enter добавляет новую строку. История обновляется при получении событий Telegram. Клиент держит в памяти до 400 последних загруженных сообщений для каждого из 150 открытых чатов до 6 часов. При повторном открытии история появляется сразу. Если с последней загрузки прошло 15 минут или чат изменился, клиент запрашивает обновление в фоне. История с самоуничтожающимися сообщениями остаётся только в открытом чате.
- Ответы в текущем чате с карточкой цитаты. Нажатие на карточку открывает исходное сообщение. Клиент загружает цитаты за пределами текущей страницы, если они доступны.
- Форматирование выделенного текста через контекстное меню редактора. Доступны полужирный, курсив, подчёркивание, зачёркивание и моноширинный шрифт. Стили отображаются в истории и сохраняются в черновике при смене чата. Текстовый спойлер скрывает выделенный фрагмент в истории, списке чатов, результатах поиска и карточках ответа. В истории нажмите на скрытый фрагмент или выберите его с клавиатуры и нажмите Enter.
- Редактирование своих текстовых сообщений с поддерживаемым форматированием. Telegram определяет срок и права для правки.
- «Перемешать варианты» доступно для опроса и викторины. Участники видят устойчивый случайный порядок, одинаковый в карточке и диалоге голосования; создатель видит исходный. Обновление результатов, переключение чата и новые варианты не перемешивают уже существующие ответы заново. Голос привязан к идентификатору ответа.
- «Только для подписчиков» доступно в каналах и супергруппах. Голосовать могут текущие участники, вступившие минимум за 24 часа до публикации; Telegram проверяет это перед голосованием. Условие видно в карточке и диалоге голосования, серверный отказ получает пояснение. В каналах доступны только анонимные опросы.
- «Ограничить участие по странам» раскрывает поиск и список стран. Выберите одну или несколько; отключение настройки снова разрешает все страны, не стирая выбор внутри редактора. Условие относится к стране номера аккаунта Telegram, а не местоположению устройства, и показано на карточке и перед голосованием. Telegram проверяет доступ; серверный отказ получает пояснение. Названия используют системный перевод iso-codes, при его отсутствии — английские названия.
- При создании обычного опроса можно включить «Запретить переголосование»: после первого отправленного выбора клиент не предлагает изменение или отзыв. Это объясняется в карточке и перед голосованием. В викторине запрет обязателен; при возврате к обычному опросу прежняя настройка восстанавливается.
- В обычном публичном опросе включите «Участники могут добавлять варианты». Новые варианты добавляются из контекстного меню карточки. Удалить такой вариант может создатель опроса или автор варианта в течение времени, заданного Telegram. После истечения срока или закрытия опроса изменения недоступны.
- Текст сообщений и подписи к вложениям можно выделить мышью и скопировать через Ctrl+C или контекстное меню. Меню копирует весь видимый текст, если ничего не выделено. Ссылки из Telegram и обычные веб-адреса открываются по щелчку или с клавиатуры в системном приложении.
- Удаление своих сообщений для всех участников чата после подтверждения. Действуют права и ограничения Telegram.
- Удаление сообщений из «Избранного», включая сохранённые пересылки. В «Избранном» удаляется сохранённая копия.
- В редакторе опросов можно выбрать интервал или местные дату и время завершения. Для опроса со сроком можно скрыть итоги от участников до завершения. В открытом чате голосование останавливается по сроку, а подтверждённые итоги появляются в карточке.
- Пересылка одного сообщения в доступный чат из списка. Telegram применяет ограничения на пересылку защищённых и самоуничтожающихся сообщений.
- Опросы и викторины в истории чата. Можно выбрать один или несколько ответов, изменить или отозвать голос, если Telegram разрешает, и увидеть результаты и пояснение викторины. В меню вложений пункт «Опрос» создаёт обычный опрос с 2–12 вариантами, анонимным или публичным голосованием. [Опросы Telegram](https://core.telegram.org/api/poll).
- Закрепление и открепление сообщений без уведомления участников. Закреплённые сообщения отмечаются в загруженной истории, права проверяет Telegram.
- В контекстном меню обычного опроса или викторины можно завершить голосование. Действие доступно у своего сообщения и у публикаций канала при наличии права редактирования. После подтверждения Telegram останавливает приём голосов и сохраняет результаты.
- Обычные эмодзи-реакции в истории с количеством и отметкой своей реакции. Эмодзи можно выбрать в контекстном меню. Доступный набор и число реакций определяет Telegram.
- Для создания викторины выберите «Опрос» в меню вложений и включите переключатель «Викторина». Отметьте правильные варианты и добавьте пояснение, если нужно.
- Поиск по тексту сообщений во всех чатах или в открытом чате с переходом к найденному сообщению. Ctrl+F открывает поиск в текущем чате, Ctrl+Shift+F — общий поиск, Escape закрывает его. Результаты загружаются страницами по 50 сообщений: следующие появляются при прокрутке или по кнопке «Показать ещё». При ошибке страницу можно запросить повторно.
- В контекстном меню публичного опроса выберите «Кто проголосовал». Список показывает все голоса или голоса за один вариант, страницы открываются кнопкой «Показать ещё». Доступ зависит от участия, настроек опроса и ответа Telegram.

### Чаты, уведомления и администрирование

- Адаптивный интерфейс GNOME с системной темой, акцентным цветом и списком чатов с поиском по названию.
- Архив чатов с переключением списка и возвратом чата из архива. Показываются архивные чаты из загруженных диалогов.
- Уведомления GNOME о новых сообщениях при запущенном клиенте. Нажатие открывает чат из загруженных диалогов. Уведомление показывает название чата, учитывает настройки уведомлений для чата и категории и исключает сообщения с таймером. Открытый активный чат обновляется без уведомления. Оповещения из связанной группы обсуждения учитывают настройки группы и канала. Для комментариев оповещения приходят при упоминаниях и ответах на ваши сообщения. В группах, в которых вы не состоите, обычные сообщения остаются без оповещений.
- Кнопка уведомлений в заголовке чата выключает их без ограничения времени или включает для этого чата. Настройка сохраняется в Telegram; звук и настройки историй сохраняются. Отключённые уведомления отмечаются в списке чатов и учитываются фильтрами папок, в том числе при наследовании настройки категории. В «Избранном» кнопка скрыта.
- Просмотр папок, настроенных в Telegram, включая импортированные общие папки. Фильтры и закрепления папки применяются к загруженным диалогам.
- Ручные отметки «прочитанным» и «непрочитанным» в контекстном меню чата. Ручная отметка без новых сообщений отображается точкой, отдельно от счётчика, и учитывается папками. Отметка открытого чата сохраняется при фоновом обновлении до явного повторного открытия или команды «Отметить прочитанным». Чтение применяется к последнему сообщению, известному при открытии меню; новые сообщения сверяются с Telegram.
- Закрепление и открепление чатов через правый щелчок по строке списка или Shift+F10 / клавишу меню. Закрепления общего списка, архива и каждой папки независимы. Закреплённые чаты отмечены значком и находятся сверху; последнее закрепление помещается первым. Остальные чаты упорядочены по времени последнего сообщения. Ограничения на число закреплений проверяет Telegram.
- Список контактов с аватарками, поиском по имени, активным username и доступному номеру телефона. Выбор открывает переписку, включая контакты вне загруженного списка чатов. Список кешируется на пять минут; кнопка обновления запрашивает его заново. При поиске и прокрутке виджеты создаются для видимых строк.
- Информация о пользователе, группе или канале по нажатию на заголовок чата. Показываются аватарка, описание, активные имена пользователя, доступный номер телефона, число участников или подписчиков и отметки Telegram. Имя пользователя и телефон можно скопировать. Состав данных определяется доступом текущего аккаунта.
- В карточке группы или канала владелец либо администратор с правом изменения данных может редактировать название и описание. Список участников или подписчиков подгружается постранично и фильтруется по администраторам и ботам, если Telegram разрешает его просмотр.
- Владелец или администратор с правом блокировки может удалить участника обычной группы с сохранением его сообщений. В супергруппах и каналах доступны блокировка и снятие блокировки через фильтр «Заблокированные». После снятия блокировки участник может вступить снова по правилам чата. Для каждой операции нужно подтверждение.
- В списке участников владелец обычной группы может назначать и снимать администраторов. В супергруппах и каналах владелец и администраторы с правом назначения могут выбирать права, которые Telegram разрешает им передавать. Кнопка появляется у участников и администраторов, роль которых можно менять. Снятие прав сохраняет участника в чате.
- Через «Добавить участников» в списке участников или карточке чата можно пригласить несколько контактов. Результат показывается отдельно для каждого контакта. Для неподтверждённых приглашений можно обновить список и сверить, кто уже в чате. Доступ к добавлению определяется правами Telegram.
- В меню приложения выберите «Создать чат». Можно создать обычную группу с участниками, супергруппу или канал, указать описание и выбрать контакты. Для супергруппы и канала пустое публичное имя сохраняет чат закрытым. Когда Telegram подтверждает создание, клиент открывает чат и показывает, если часть участников добавить не удалось. Если публичное имя не сохранилось, его можно изменить в том же диалоге. Публикация в канале доступна владельцу и администраторам с правом публикации.
- Владелец супергруппы или канала может открыть «Публичные адреса» в карточке чата, изменить основное имя и включить или отключить прикреплённые коллекционные имена. Для закрытия публичного доступа очистите основное имя, отключите остальные адреса и подтвердите сохранение.
- В карточке группы или супергруппы владелец и администратор с правом блокировки могут открыть «Разрешения группы». Здесь задаются общие права участников на отправку текста и каждого вида вложений, опросы, реакции, приглашение, закрепление, изменение сведений и своего тега. В форумах доступно право создавать темы. Доступность отдельных переключателей зависит от прав администратора и типа группы. Предпросмотр ссылок требует разрешения на отправку текста.
- В разрешениях супергруппы настройка «Медленный режим» задаёт интервал между сообщениями участников от 5 секунд до часа. При ожидании над полем ввода виден таймер, а черновик можно дописывать. После окончания ожидания отправка снова доступна.
- В списке участников супергруппы администратор с правом блокировки может открыть «Ограничения участника». Можно ограничить отдельные действия бессрочно, на день, на неделю или на свой срок. Фильтр «С ограничениями» открывает сохранённые ограничения для редактирования и снятия. После снятия действуют общие разрешения группы.
- Откройте супергруппу с темами и выберите тему из списка. Кнопка «Темы» возвращает к выбору. История, черновики, ответы и ожидающие отправки вложения сохраняются отдельно для каждой темы. При пересылке в форум выбирается тема назначения. Закрытые темы доступны для чтения.
- При создании супергруппы можно сразу включить «Темы». Владелец существующей супергруппы меняет режим в карточке чата. Telegram ограничивает включение тем для привязанных групп обсуждения и учитывает минимальное число участников. Если история скрыта от новых участников, её открытие требует явного подтверждения вместе с включением тем. Черновики общего чата и отдельных тем сохраняются при смене режима.
- Кнопка «Новая тема» появляется у участников с правом создания тем. В параметрах темы можно изменить её название, закрыть, открыть, закрепить или удалить её в зависимости от прав. Общую тему можно скрыть или вернуть в список. Удаление темы вместе с её историей требует подтверждения.
- В разделе «Недавние действия» администраторы супергрупп и каналов могут посмотреть журнал Telegram, найти записи по тексту и отфильтровать их по типу события или автору. Строки с подробностями раскрываются по нажатию, более ранние записи загружаются кнопкой «Показать ещё».
- «Пригласительные ссылки» в карточке группы или канала доступны владельцу и администраторам с правом приглашения. При создании и редактировании своей дополнительной ссылки можно задать название, срок действия и выбрать лимит вступлений или одобрение администратором. Для своих ссылок с подпиской Telegram Stars можно менять название. Доступные ссылки можно копировать. Отзыв обычной ссылки требует подтверждения. Отдельный фильтр показывает отозванные ссылки.
- Раздел «Заявки на вступление» в карточке чата показывает общую очередь из всех источников. Администратор с правом приглашения может принять или отклонить заявку после подтверждения. Открытый список обновляется при получении событий Telegram.
- Карточка бота показывает доступные команды. Нажатие добавляет команду в поле ввода, сохраняя уже набранный текст.

### Медиа и вложения

- Отправка одного файла или альбома из 2–10 фотографий либо документов с подписью. Выберите несколько файлов за один раз в меню вложений. Режим «Файлы» сохраняет исходные байты, режим «Фотографии» использует обработку изображений Telegram. В истории альбом занимает одну карточку. Отдельное вложение можно открыть или сохранить через его контекстное меню. Сервер применяет ограничения аккаунта и чата.
- Крупные миниатюры. На карточке видео показаны размер файла и длительность при наличии данных. Фото и видео открываются в отдельных окнах, а чат остаётся доступным для ввода. В GNOME с включённым центрированием новых окон просмотр появляется по центру рабочей области с учётом панелей и дока. Окно подстраивается под пропорции и занимает до четверти площади монитора, включая заголовок. Из окна можно сохранить оригинал, а для фото также скопировать изображение из предпросмотра. Клиент загружает предпросмотр фотографии размером до 1600 × 1600. Вложения с таймером исключены.
- Имена и аватарки авторов входящих и исходящих сообщений. В списке групп рядом с последним сообщением отображается имя автора. В истории для сообщений от имени группы или канала используются название и аватарка отправившего чата, включая публикации от другого канала. Если Telegram не отдаёт название, показывается тип отправителя. В превью последнего сообщения, включая каналы, показывается компактная миниатюра доступного вложения. Когда фото профиля недоступно, отображаются инициалы. У фотографий и документов с серверной миниатюрой есть изображение в истории. Вложения со спойлером и таймером не показывают миниатюру автоматически.
- Музыка и голосовые воспроизводятся в карточке сообщения. Одна кнопка запускает и приостанавливает запись, а перемотка доступна на дорожке музыки или звуковой волне голосового. Карточка сохраняет размер при загрузке и воспроизведении. Название, обложка, исполнитель и длительность показываются при наличии данных. При смене чата или запуске другой записи воспроизведение останавливается.
- Видео и музыка читаются фрагментами, а перемотка запрашивает нужный участок. Проигрыватель получает фрагменты через поток GTK с перемоткой и ограниченным кешем в памяти. Голосовые загружаются целиком. Если проигрыватель не может открыть поток, доступна повторная попытка с полной загрузкой. Для полной загрузки доступно до 4 ГиБ во временном файле. Форматы и потоковое чтение зависят от GTK/GStreamer и установленных плагинов. В окне видео Пробел переключает паузу, стрелки перематывают на пять секунд, Escape закрывает окно и завершает воспроизведение.

### Деморежим

Деморежим с вымышленными чатами, локальной отправкой сообщений, имитацией отправки вложений и скачиваемым тестовым файлом. Подключение к Telegram для деморежима не требуется.

## Ограничения Telegram API

- Спонсорские сообщения Telegram не запрашиваются и не отображаются.
- Документы и фотографии можно сохранить через системный диалог, в том числе из чатов с запретом на сохранение. Загрузка требует доступа к сообщению и файлу на сервере. При истечении ссылки клиент один раз заново запрашивает сообщение и повторяет загрузку того же файла. Сохранение самоуничтожающихся сообщений и вложений с таймером отключено.

У Telegram есть требования к показу спонсорских сообщений и обработке запретов на сохранение. С этими настройками Telegram может отключить доступ приложения к API. См. [условия Telegram API](https://core.telegram.org/api/terms) и [правила защиты контента](https://core.telegram.org/api/content-protection).

## Стикеры

Откройте «Добавить вложение» → «Стикеры». В поле «Поиск по эмодзи» можно найти стикеры Telegram, включая неустановленные наборы. Ввод запускает поиск после короткой паузы; Enter — сразу. Очистите поле или нажмите Escape в нём, чтобы вернуться к выбранному набору. Пока заполнен поиск, выбор набора и управление им скрыты или недоступны. Открытие набора по ссылке завершает поиск. В списке есть недавние, избранные и установленные неархивные наборы аккаунта. Выберите набор и нажмите стикер для отправки. Элементы доступны через Tab и Enter; поиск в списке помогает найти установленный набор. Маски и пользовательские эмодзи в этот список не входят. Список запрашивается заново при открытии окна.

Стикер отправляется отдельным сообщением в выбранный чат или тему. Выбранный ответ используется для стикера; текстовый черновик и подготовленные файлы остаются. При смене чата до выбора стикера откройте окно выбора заново. Завершение уже начатой отправки обновляет исходный чат. После ошибки повторный выбор того же стикера в открытом окне сохраняет идентификатор операции. Закрытие окна и новый выбор начинают новую операцию.

Стикеры в истории и окне выбора показываются без подписей; описание доступно во всплывающей подсказке и экранному диктору. Статические стикеры WebP показываются с прозрачностью.

TGS отрисовываются прямо в сообщении с прозрачностью. Растровая миниатюра или эмодзи остаются при загрузке и ошибке. За пределами видимой области обработчик освобождается. Принимаются TGS до 64 КиБ, распакованный JSON до 4 МиБ, холст 512 × 512 и анимация до 3 секунд/60 кадров в секунду. Внешние изображения и шрифты не загружаются. Размер карточки остаётся прежним, а кадры TGS отрисовываются с учётом масштаба монитора, до 512 × 512. При смене масштаба сохраняются текущая позиция и пауза; загруженный файл используется повторно.

Видеостикер автоматически повторяется прямо в сообщении, без звука и отдельного окна. Нажатие на изображение переключает паузу; кнопка доступна через Tab и Space/Enter. За пределами видимой области декодер освобождается; возвращение к сообщению использует уже загруженный файл. При уходе из чата загрузка отменяется, проигрывание останавливается и файл освобождается. После ошибки изображение остаётся, а нажатие повторяет попытку. Прозрачность VP9 требует `gstreamer1-plugins-bad-free` на Fedora. Видеостикер размером до 256 КиБ полностью загружается перед просмотром. Отдельный обработчик GStreamer передаёт кадры в сообщение через очередь с одним кадром, сохраняя исходное разрешение до 512 × 512 для HiDPI. При скрытии сообщения конвейер синхронно останавливается перед освобождением элементов; исходный файл остаётся до ухода из чата. Ограничения аккаунта, Premium и права чата применяет Telegram. После отправки клиент также пытается сохранить стикер в недавние; сбой этой операции не требует повторной отправки.

Доступный стикер можно сохранить через контекстное меню сообщения в исходном формате. Для самоуничтожающихся сообщений и медиа с таймером просмотр и сохранение отключены. Политика ручного сохранения из защищённых чатов остаётся той же, что для других вложений; действуют описанные выше ограничения Telegram API.

Кнопка со звездой под стикером добавляет его в избранное или убирает оттуда. Изменение не отправляет сообщение. Клиент сверяет результат с серверным списком, в том числе после потери ответа. Если результат неизвестен, обновите набор перед повтором. Закрытие окна не отменяет уже начатый запрос; повторное открытие получает актуальный список. В деморежиме избранное сохраняется до закрытия окна аккаунта и отдельно для каждого демоаккаунта.

Кнопка «Открыть набор по ссылке» принимает короткое имя, ссылку `https://t.me/addstickers/…` или `tg://addstickers?set=…`. Набор можно просмотреть до установки и отправить из него стикер. «Добавить набор» устанавливает его в аккаунте. «Убрать набор» запрашивает подтверждение; отправленные сообщения и избранные стикеры сохраняются. После удаления набор остаётся открыт как предпросмотр, а при следующем открытии списка исчезает из установленных. Если Telegram при установке архивировал другие наборы из-за лимита, результат сообщает их число; откройте список заново для обновления. Изменение проверяется чтением серверного состояния, включая потерянный ответ. Маски и наборы пользовательских эмодзи исключены.
