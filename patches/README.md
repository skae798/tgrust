# Локальная правка grammers-client 0.12.0

Каталог `grammers-client` содержит исходники опубликованного пакета 0.12.0 из crates.io. Контрольная сумма исходного пакета SHA-256: `0d72e6a294d409c22c860d442bc78894507c0ad066733acc27c5d23fed8ef9bb`. Изменения исходного кода вынесены в `grammers-client-search.patch`. В манифесте удалены повторяющийся `homepage` и локальный `resolver`, который задаёт workspace. Исключён upstream-тест `deps`, подключающий отсутствующий в опубликованном пакете файл из монорепозитория, и его зависимость `toml`. Примеры upstream оставлены для справки; их цели и dev-зависимости исключены, поскольку они требуют `TG_ID` и `TG_HASH` при компиляции. Пробелы в конце строк README примеров удалены для `git diff --check`.

Версии остальных пакетов grammers сохранены из исходного Cargo.lock, схема Telegram не менялась. Лицензии upstream сохранены в каталоге пакета.

В `src/client/messages.rs` исправлены два условия глобального поиска:

- Номер сообщения в одном чате больше не завершает поиск по другим чатам. Для глобальной выдачи страница считается последней при пустом ответе или полном ответе `messages.messages`.
- При отсутствии `next_rate` следующий `offset_rate` получает дату последнего сообщения, как требует [messages.searchGlobal](https://core.telegram.org/method/messages.searchGlobal).

Правка конца страницы покрыта регрессионными тестами. Запуск: `cargo test --locked -p grammers-client --lib --no-default-features`. Этот шаг включён в CI. При замене локальной копии на новую версию upstream проверьте оба случая и совместимость всех пакетов grammers.
